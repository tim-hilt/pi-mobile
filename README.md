# pi-native-client

Native iOS client for the [pi](https://github.com/badlogic/pi-mono) agent.

| Path               | What                                                     |
| ------------------ | -------------------------------------------------------- |
| `bridge/`          | Node/TypeScript server embedding pi, speaks the protocol |
| `ios/`             | SwiftUI app (Xcode project generated by XcodeGen)        |
| `docs/protocol.md` | Bridge Protocol — the contract between the two           |

## Develop

Bridge (Node 22+):

```sh
npm install        # also installs git hooks
npm test           # vitest
npm run typecheck
```

iOS (Xcode, `brew install xcodegen`):

```sh
cd ios && xcodegen generate   # after editing project.yml
xcodebuild test -scheme PiClient -destination 'platform=iOS Simulator,name=iPhone 18 Pro'
```

Pre-commit runs Prettier, typecheck, and bridge tests; failure blocks the commit.
